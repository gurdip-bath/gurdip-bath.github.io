Contoso IT Helpdesk Assistant

Copilot Studio · Generative AI IT support agent

Portfolio project
Copilot Studio Dataverse SharePoint Model-Driven App GPT-5
Role
Sole developer — agent design, topics, Dataverse schema, escalation flows
Domain
IT helpdesk · First-line support
Type
Portfolio build · Copilot Studio agent
Stack
Copilot Studio · Dataverse · SharePoint · GPT-5

Problem

IT support teams field repetitive first-line queries around password resets, software access, and device issues — often outside core hours. Staff need a consistent, governed AI assistant that can answer from knowledge sources and escalate complex tickets without losing context.

Solution

  • 5-section system prompt framework — Role, Scope, Behaviour, Constraints, Citation Rules, and Fallback
  • Knowledge grounding from SharePoint and structured Dataverse sources
  • Multi-step ticket escalation topic with Adaptive Card and GPT-5 Prompt node

Architecture

  • Generative AI agent in Microsoft Copilot Studio serving as a 24/7 first-line IT support assistant
  • 5-section system prompt framework governing role, scope, behaviour, constraints, and citation rules
  • Multi-step ticket escalation topic using an Adaptive Card and a GPT-5 Prompt node
  • Switch() priority-mapping variable to translate severity labels into Dataverse ticket priority
  • 2-table Dataverse schema — Support Tickets and IT Asset Inventories
  • Model-driven app for support staff to manage escalated tickets and asset records
